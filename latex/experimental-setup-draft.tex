\section{Experimental Setup and Results}
\label{sec:experimental_setup_results}

The experiments evaluate deterministic short-term vessel trajectory forecasting on the compact EnvShip-Bench paper benchmark. The goal is to predict the next 10 minutes of vessel motion from the previous 10 minutes under a unified 30$\rightarrow$30 forecasting protocol. All models are evaluated on the same curated compact split family so that architectural differences, rather than dataset-version differences, explain performance differences.

The evaluation reported here focuses on coordinate-only deterministic forecasting. We compare five recurrent baselines, namely Seq2Seq, GRU, Bi-GRU, LSTM, and Bi-LSTM, against a single invertible forecasting model, Kine-Real-NVP. The Kine-Real-NVP model corresponds to the KineRoute-NVP implementation used in this repository, but the run name in the results section is written as Kine-Real-NVP for easier comparison with the baseline family.

\subsection{Execution Environment}
\label{subsec:execution_environment}

Experiments were run on an NVIDIA GeForce RTX 2050 GPU with 4 GB of memory in the local \texttt{data\_science} Python environment. Training used PyTorch with CUDA execution. For reproducibility, every compact-benchmark run was launched from a checked-in experiment YAML and wrote a fully resolved configuration, command record, per-epoch metric log, checkpoints, and final machine-readable metrics into a timestamped results directory under \texttt{results/}.

\subsection{Forecasting Protocol}
\label{subsec:forecasting_protocol}

All benchmark samples follow the same short-term maritime forecasting protocol:
\begin{itemize}
\item observation horizon: 10 minutes,
\item prediction horizon: 10 minutes,
\item sampling interval: 20 seconds,
\item history length: 30 points,
\item future length: 30 points.
\end{itemize}

Each trajectory is represented in vessel-centric local planar coordinates measured in meters, with the last observed point acting as the anchor. Deterministic forecasting is evaluated with Average Displacement Error (ADE) and Final Displacement Error (FDE), both in meters.

\subsection{Datasets}
\label{subsec:datasets}

The experiments use the official EnvShip-Bench release on Hugging Face published by \texttt{mark000071}. We intentionally use the compact paper subsets rather than the later cross-domain v2 release. Specifically, we combine the DMA mini benchmark subset \texttt{clean\_ship\_core\_lite\_v1} with the NOAA mini benchmark subset \texttt{clean\_ship\_core\_lite\_v1}.

Within the repository, these two subsets are exposed under \texttt{data/envship/} through the local aliases \texttt{paper\_dma\_clean\_ship\_core\_lite\_v1} and \texttt{paper\_noaa\_clean\_ship\_core\_lite\_v1}.

The resulting combined split sizes are:
\[
N_{\mathrm{train}} = 29635,\qquad
N_{\mathrm{val}} = 3667,\qquad
N_{\mathrm{test}} = 3262.
\]

The DMA compact subset contributes 19,500 training windows and the NOAA compact subset contributes 10,135 training windows, giving a combined compact benchmark that is closely aligned with the paper's controlled experimental setting.

\subsection{Dataset-Specific Preprocessing}
\label{subsec:dataset_specific_preprocessing}

Each CSV row is one fixed-length vessel-trajectory sample containing 30 historical points and 30 future points. The preprocessing pipeline parses the \texttt{hist\_x\_json}, \texttt{hist\_y\_json}, \texttt{fut\_x\_json}, and \texttt{fut\_y\_json} arrays and stores them in compressed NumPy artifacts for training.

For the recurrent baselines, the raw coordinate history and future arrays are used directly, followed by normalization computed from the training split only. For Kine-Real-NVP, the compact benchmark is additionally transformed with two geometric preprocessing steps:
\begin{itemize}
\item alignment to the last observed heading,
\item displacement-chart encoding of the future trajectory.
\end{itemize}

Heading alignment rotates each sample so that the last observed motion direction is canonicalized. The displacement chart represents the future as stepwise displacements rather than absolute future positions. This substantially reduces directional variance and makes the target representation easier to model on the compact benchmark.

\subsection{Models}
\label{subsec:models}

\subsubsection{Recurrent Baselines}

Five recurrent baselines are evaluated under the same compact-benchmark protocol.

The Seq2Seq model uses a GRU encoder and a GRU decoder with teacher forcing during training. The GRU and Bi-GRU baselines use a recurrent encoder followed by a multilayer perceptron head that predicts the full 30-step future. The LSTM and Bi-LSTM baselines use the same prediction head structure but replace the GRU encoder with an LSTM encoder.

All recurrent baselines use hidden dimension 128 and 2 recurrent layers. Their parameter counts are:
\begin{itemize}
\item Seq2Seq: 299,778,
\item GRU: 174,012,
\item Bi-GRU: 438,460,
\item LSTM: 223,932,
\item Bi-LSTM: 571,068.
\end{itemize}

\subsubsection{Kine-Real-NVP}

Kine-Real-NVP is an invertible supervised forecasting model built from routed RealNVP-style affine coupling blocks over a kinematic trajectory chart. In the compact-benchmark experiments, the strongest configuration uses:
\begin{itemize}
\item 6 routed coupling blocks,
\item hidden dimension 256,
\item 2 hidden layers per coupling network,
\item scale bound 1.5,
\item heading-aligned displacement-chart targets,
\item pure ADE optimization without auxiliary physics penalties.
\end{itemize}
