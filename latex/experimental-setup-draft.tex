\section{Experimental Setup and Results}
\label{sec:experimental_setup_results}

The experiments evaluate deterministic short-term vessel trajectory forecasting on the compact EnvShip-Bench paper benchmark. The goal is to predict the next 10 minutes of vessel motion from the previous 10 minutes under a unified 30$\rightarrow$30 forecasting protocol. All models are evaluated on the same curated compact split family so that architectural differences, rather than dataset-version differences, explain performance differences.

The evaluation reported here focuses on coordinate-only deterministic forecasting. We compare five recurrent baselines, namely Seq2Seq, GRU, Bi-GRU, LSTM, and Bi-LSTM, against a single invertible forecasting model, Kine-Real-NVP. The Kine-Real-NVP model corresponds to the KineRoute-NVP implementation used in this repository, but the run name in the results section is written as Kine-Real-NVP for easier comparison with the baseline family.

\subsection{Execution Environment}
\label{subsec:execution_environment}

Experiments were run on an NVIDIA GeForce RTX 2050 GPU with 4 GB of memory in the local \texttt{data\_science} Python environment. Training used PyTorch with CUDA execution. For reproducibility, every compact-benchmark run was launched from a checked-in experiment YAML and wrote a fully resolved configuration, command record, per-epoch metric log, checkpoints, and final machine-readable metrics into a timestamped results directory under \texttt{results/}.

\subsection{Forecasting Protocol}
\label{subsec:forecasting_protocol}

All benchmark samples follow the same short-term maritime forecasting protocol:
\begin{itemize}
\item observation horizon: 10 minutes,
\item prediction horizon: 10 minutes,
\item sampling interval: 20 seconds,
\item history length: 30 points,
\item future length: 30 points.
\end{itemize}

Each trajectory is represented in vessel-centric local planar coordinates measured in meters, with the last observed point acting as the anchor. Deterministic forecasting is evaluated with Average Displacement Error (ADE) and Final Displacement Error (FDE), both in meters.
